直接在網頁上原地翻譯圖片裡的文字。

不必再截圖、儲存、上傳給 AI、閱讀、再切回來。在圖片上按右鍵，或在網頁任何地方拖曳框選，Snap Translate 就會抹去圖片裡的原文，並以相同的顏色、大小和粗細把譯文放回原處。圖片讀起來就像本來就是用你的語言做的。

兩種開始方式
• 在圖片上按右鍵並選擇「翻譯圖片」
• 或按 Alt + Shift + T（Mac 為 ⌥ ⇧ T），或在網頁上按右鍵選擇「翻譯區域…」，或使用彈出視窗裡的按鈕，然後拖曳框選要翻譯的文字。影片畫面、背景圖和 canvas 上同樣適用
• 按 Esc 取消；可在 Chrome 的快速鍵設定中改用其他快速鍵

圖片上或清單
• 圖片上（預設）：從圖片中抹去原文，並依從圖片量得的顏色、大小、粗細和對齊方式把譯文放回原處。全部在你的電腦上完成，不花任何費用
• 譯文太長放不下時，會改在旁邊顯示一個小泡泡，並以一條線連到原文
• 清單：每段文字和它的譯文顯示在圖片旁的卡片裡。點一行即可複製，也可以一次全部複製
• 名稱、價格以及已經是你的語言的文字保持不變

選擇翻譯引擎
• 快速（預設）：免費，不需金鑰。在你的電腦上辨識越南文和英文文字，再由 Google 翻譯進行翻譯。最適合菜單、貼文、截圖這類清楚的文字
• Gemini：Google AI Studio 的免費金鑰，有每日上限。不論哪種語言，辨識迷因、手寫和花俏字體都好得多
• Claude：依用量付費，使用你自己的 API 金鑰
• 本機：搭配 Ollama 或 LM Studio 和能看圖的模型，免費且離線
• 其他：任何相容 OpenAI 的 API，例如 OpenRouter
• 可翻譯成：越南文、捷克文、英文、斯洛伐克文、德文、法文、西班牙文、義大利文、葡萄牙文、波蘭文、匈牙利文、烏克蘭文、荷蘭文、瑞典文、丹麥文、挪威文、芬蘭文、希臘文、土耳其文、羅馬尼亞文、克羅埃西亞文、中文（簡體和繁體）、日文、韓文、泰文、印尼文、馬來文、菲律賓文、印地文、阿拉伯文

31 種語言的介面
彈出視窗以及 Snap Translate 在網頁上顯示的所有內容，都支援它能翻譯的全部 31 種語言，包括阿拉伯文（由右至左）。預設跟隨瀏覽器，也可以在「語言與外觀」中選擇。深色、淺色或與瀏覽器相同。

隱私
在你要求翻譯之前，什麼都不會離開瀏覽器。使用「快速」時，圖片留在你的電腦裡，只有圖片中辨識出的文字會傳送給 Google 翻譯。使用 AI 翻譯引擎時，只有你所選區域的截圖會連同你的 API 金鑰傳送給該服務商。金鑰只儲存在這台裝置上。沒有分析統計，沒有帳號。擴充功能只在你開始翻譯的那個分頁中執行，絕不會在所有網站上執行。如果你透過「問題或想法？」寫信給我，訊息會以電子郵件寄到我這裡，在你按下「傳送」之前不會傳送任何內容。

問題或想法？
點擊彈出視窗底部的「問題或想法？」寫信給我。每封訊息我都會讀。
