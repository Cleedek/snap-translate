画像の中の文字を、ページ上のその場で翻訳します。

スクリーンショットを撮って、保存して、AI にアップロードして、読んで、戻る。そんな手間はもう不要です。画像を右クリックするか、ページのどこでもドラッグするだけで、Snap Translate が画像から元の文字を消し、同じ色・大きさ・太さで翻訳をその場所に配置します。画像がまるで最初からあなたの言語で作られたように読めます。

★ 主な特長
★ 画像を右クリックして「画像を翻訳」を選ぶか、ページのどこでもドラッグ
★ 翻訳は画像の上、元の文字があった場所に直接入ります
★ リストの方が好き？ 画像の横に各行を表示し、クリックでコピー
★ 31 言語に翻訳
★ 最初のクリックから無料：キー不要、アカウント不要、画像はパソコンの中に残ります
★ 必要なら AI でもっと賢く：Gemini、Claude、ローカルモデル、または OpenAI 互換の任意の API
★ 動画のフレーム、背景、canvas も対象：ページ上に見えるものなら何でも
★ 無料のオープンソース：広告なし、アカウントなし、トラッキングなし

2 つの始め方
• 画像を右クリックして「画像を翻訳」を選ぶ
• または Alt + Shift + T（Mac では ⌥ ⇧ T）を押すか、ページを右クリックして「範囲を翻訳…」を選ぶか、ポップアップのボタンを使い、翻訳したい文字の上をドラッグ。動画のフレーム、背景、canvas でも使えます
• Esc でキャンセル。別のショートカットは Chrome のショートカット設定で変更できます

画像上またはリストで
• 画像上（既定）：元の文字を画像から消し、画像から測った色・大きさ・太さ・配置で翻訳をその場所に置きます。すべてパソコンの中で行われ、費用はかかりません
• 収まりきらない長い翻訳は、代わりに横に小さな吹き出しで表示され、元の文字へ線でつながります
• リスト：各テキストと翻訳を画像の横のカードに表示。行をクリックしてコピー、またはまとめてコピー
• 名前、価格、すでにあなたの言語で書かれた文字はそのまま残ります

翻訳エンジンを選ぶ
• クイック（既定）：無料、キー不要。ベトナム語と英語の文字をパソコン上で読み取り、Google 翻訳が翻訳します。メニュー、投稿、スクリーンショットのようなはっきりした文字に最適です
• Gemini：Google AI Studio の無料キー（1 日の上限あり）。ミーム、手書き、装飾フォントをどの言語でもはるかに上手に読み取ります
• Claude：使った分だけ支払い、ご自身の API キーで利用
• ローカル：Ollama または LM Studio と画像を理解できるモデルで、無料かつオフライン
• その他：OpenAI 互換の任意の API（例：OpenRouter）
• 翻訳先：ベトナム語、チェコ語、英語、スロバキア語、ドイツ語、フランス語、スペイン語、イタリア語、ポルトガル語、ポーランド語、ハンガリー語、ウクライナ語、オランダ語、スウェーデン語、デンマーク語、ノルウェー語、フィンランド語、ギリシャ語、トルコ語、ルーマニア語、クロアチア語、中国語（簡体字・繁体字）、日本語、韓国語、タイ語、インドネシア語、マレー語、フィリピン語、ヒンディー語、アラビア語

31 言語のインターフェース
ポップアップと、Snap Translate がページ上に表示するすべてが、翻訳先と同じ 31 言語に対応しています。アラビア語（右から左）も含みます。ブラウザの言語に合わせるか、「言語と外観」で選べます。ダーク、ライト、またはブラウザと同じ。

プライバシー
翻訳を頼むまで、ブラウザから何も送信されません。クイックでは画像はパソコンの中に残り、画像内で見つかった文字だけが Google 翻訳に送られます。AI の翻訳エンジンでは、選んだ範囲のスクリーンショットだけが、あなたの API キーとともにその提供元に送られます。キーはこのデバイスにだけ保存されます。アナリティクスもアカウントもありません。拡張機能は翻訳を始めたタブでだけ動作し、すべてのサイトで動くことはありません。「問題やアイデアは？」から私に書いた場合、メッセージはメールで届き、「送信」を押すまで何も送られません。

問題やアイデアは？
ポップアップ下部の「問題やアイデアは？」をクリックして、気軽に書いてください。すべてのメッセージを読んでいます。
