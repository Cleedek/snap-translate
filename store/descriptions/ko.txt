이미지 속 글자를 페이지 위 그 자리에서 번역하세요.

스크린샷을 찍고, 저장하고, AI에 올리고, 읽고, 다시 돌아오는 일은 이제 그만. 이미지를 마우스 오른쪽 버튼으로 클릭하거나 페이지 어디든 드래그하면, Snap Translate가 이미지에서 원래 글자를 지우고 같은 색, 크기, 굵기로 번역을 그 자리에 넣어 줍니다. 이미지가 처음부터 내 언어로 만들어진 것처럼 읽힙니다.

★ 주요 기능
★ 이미지를 마우스 오른쪽 버튼으로 클릭하고 "이미지 번역"을 선택하거나, 페이지 어디든 드래그
★ 번역이 원래 글자가 있던 이미지 위에 바로 들어갑니다
★ 목록이 더 편하신가요? 이미지 옆에서 각 줄을 보고 클릭해서 복사
★ 31개 언어로 번역
★ 첫 클릭부터 무료: 키도 계정도 필요 없고, 이미지는 내 컴퓨터에 그대로
★ 원하면 AI로 더 똑똑하게: Gemini, Claude, 로컬 모델 또는 OpenAI 호환 API
★ 동영상 프레임, 배경, canvas도 가능: 페이지에 보이는 것이라면 무엇이든
★ 무료 오픈 소스: 광고 없음, 계정 없음, 추적 없음

━━━━━━━━━━━━━━━━━━━━

시작하는 두 가지 방법
• 이미지를 마우스 오른쪽 버튼으로 클릭하고 "이미지 번역" 선택
• 또는 Alt + Shift + T(Mac에서는 ⌥ ⇧ T)를 누르거나, 페이지를 마우스 오른쪽 버튼으로 클릭해 "영역 번역…"을 선택하거나, 팝업의 버튼을 누른 뒤 번역할 글자 위를 드래그. 동영상 프레임, 배경, canvas에서도 작동합니다
• Esc로 취소. 다른 단축키는 Chrome 단축키 설정에서 바꿀 수 있습니다

이미지 위 또는 목록으로
• 이미지 위(기본): 원래 글자를 이미지에서 지우고, 이미지에서 측정한 색, 크기, 굵기, 정렬로 번역을 그 자리에 넣습니다. 모두 내 컴퓨터에서 처리되며 비용이 들지 않습니다
• 자리에 비해 너무 긴 번역은 대신 옆에 작은 말풍선으로 표시되고, 원래 글자와 선으로 이어집니다
• 목록: 각 텍스트와 번역을 이미지 옆 카드에 표시. 줄을 클릭해 복사하거나 한 번에 모두 복사
• 이름, 가격, 이미 내 언어로 된 글자는 그대로 둡니다

번역기 선택
• 빠른 번역(기본): 무료, 키 불필요. 내 컴퓨터에서 베트남어와 영어 글자를 읽고 Google 번역이 번역합니다. 메뉴, 게시물, 스크린샷처럼 깔끔한 글자에 가장 잘 맞습니다
• Gemini: Google AI Studio의 무료 키(하루 한도 있음). 밈, 손글씨, 장식 글꼴을 어떤 언어든 훨씬 잘 읽습니다
• Claude: 사용한 만큼 지불, 내 API 키 사용
• 로컬: Ollama 또는 LM Studio와 이미지를 볼 수 있는 모델로 무료, 오프라인
• 기타: OpenAI 호환 API(예: OpenRouter)
• 번역 언어: 베트남어, 체코어, 영어, 슬로바키아어, 독일어, 프랑스어, 스페인어, 이탈리아어, 포르투갈어, 폴란드어, 헝가리어, 우크라이나어, 네덜란드어, 스웨덴어, 덴마크어, 노르웨이어, 핀란드어, 그리스어, 튀르키예어, 루마니아어, 크로아티아어, 중국어(간체, 번체), 일본어, 한국어, 태국어, 인도네시아어, 말레이어, 필리핀어, 힌디어, 아랍어

31개 언어 인터페이스
팝업과 Snap Translate가 페이지에 보여 주는 모든 것이 번역 가능한 31개 언어 모두로 제공되며, 아랍어(오른쪽에서 왼쪽)도 포함됩니다. 브라우저 언어를 따르거나 "언어 및 모양"에서 고를 수 있습니다. 다크, 라이트 또는 브라우저와 동일.

개인정보 보호
번역을 요청하기 전까지는 아무것도 브라우저 밖으로 나가지 않습니다. 빠른 번역에서는 이미지가 내 컴퓨터에 남고, 이미지에서 찾은 글자만 Google 번역으로 보내집니다. AI 번역기를 쓰면 선택한 영역의 스크린샷만 내 API 키와 함께 해당 제공업체로 보내집니다. 키는 이 기기에만 저장됩니다. 분석 도구도 계정도 없습니다. 확장 프로그램은 번역을 시작한 탭에서만 작동하며, 모든 사이트에서 작동하는 일은 없습니다. "문제나 아이디어가 있나요?"로 연락하시면 메시지는 이메일로 전달되며, "보내기"를 누르기 전에는 아무것도 전송되지 않습니다.

문제나 아이디어가 있나요?
팝업 아래쪽의 "문제나 아이디어가 있나요?"를 클릭해 편하게 적어 주세요. 모든 메시지를 읽습니다.
