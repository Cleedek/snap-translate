直接在网页上原地翻译图片里的文字。

不用再截图、保存、上传给 AI、阅读、再切回来。右键点击图片，或在网页任意位置拖动框选，Snap Translate 就会抹去图片里的原文，并用相同的颜色、大小和粗细把译文放回原处。图片读起来就像本来就是用你的语言做的。

两种开始方式
• 右键点击图片并选择"翻译图片"
• 或按 Alt + Shift + T（Mac 上为 ⌥ ⇧ T），或右键点击网页选择"翻译一个区域…"，或使用弹出窗口里的按钮，然后拖动框选要翻译的文字。视频画面、背景图和 canvas 上同样适用
• 按 Esc 取消；可在 Chrome 的快捷键设置中改用其他快捷键

图上或列表
• 图上（默认）：从图片中抹去原文，并按从图片测得的颜色、大小、粗细和对齐方式把译文放回原处。全部在你的电脑上完成，不花一分钱
• 译文太长放不下时，会改为在旁边显示一个小气泡，并用一条线连到原文
• 列表：每段文字和它的译文显示在图片旁边的卡片里。点一行即可复制，也可以一次全部复制
• 名称、价格以及已经是你的语言的文字保持不变

选择翻译引擎
• 快速（默认）：免费，无需密钥。在你的电脑上识别越南语和英语文字，再由 Google 翻译进行翻译。最适合菜单、帖子、截图这类清晰的文字
• Gemini：Google AI Studio 的免费密钥，有每日限额。无论哪种语言，识别表情包、手写和花哨字体都好得多
• Claude：按用量付费，使用你自己的 API 密钥
• 本地：配合 Ollama 或 LM Studio 和能看图的模型，免费且离线
• 其他：任何兼容 OpenAI 的 API，例如 OpenRouter
• 可翻译成：越南语、捷克语、英语、斯洛伐克语、德语、法语、西班牙语、意大利语、葡萄牙语、波兰语、匈牙利语、乌克兰语、荷兰语、瑞典语、丹麦语、挪威语、芬兰语、希腊语、土耳其语、罗马尼亚语、克罗地亚语、中文（简体和繁体）、日语、韩语、泰语、印尼语、马来语、菲律宾语、印地语、阿拉伯语

31 种语言的界面
弹出窗口以及 Snap Translate 在网页上显示的所有内容都支持它能翻译的全部 31 种语言，包括阿拉伯语（从右到左）。默认跟随浏览器，也可以在"语言和外观"中选择。深色、浅色或跟随浏览器。

隐私
在你请求翻译之前，什么都不会离开浏览器。使用"快速"时，图片留在你的电脑里，只有图片中识别出的文字会发送给 Google 翻译。使用 AI 翻译引擎时，只有你所选区域的截图会连同你的 API 密钥发送给该服务商。密钥只保存在这台设备上。没有统计分析，没有账号。扩展只在你开始翻译的那个标签页中运行，绝不会在所有网站上运行。如果你通过"问题或想法？"给我写信，消息会通过电子邮件到达我这里，在你点击"发送"之前不会发送任何内容。

问题或想法？
点击弹出窗口底部的"问题或想法？"给我留言。每条消息我都会读。
