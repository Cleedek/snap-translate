แปลข้อความในรูปภาพได้ทันที ตรงตำแหน่งเดิมบนหน้าเว็บ

ไม่ต้องจับภาพหน้าจอ บันทึก อัปโหลดให้ AI อ่าน แล้วสลับกลับมาอีกต่อไป แค่คลิกขวาที่รูปภาพหรือลากคลุมส่วนใดก็ได้ของหน้าเว็บ Snap Translate จะลบข้อความต้นฉบับออกจากรูปภาพ แล้ววางคำแปลไว้ที่เดิมด้วยสี ขนาด และความหนาเดียวกัน รูปภาพจะอ่านได้เหมือนทำมาเป็นภาษาของคุณตั้งแต่แรก

★ จุดเด่น
★ คลิกขวาที่รูปภาพแล้วเลือก "แปลรูปภาพ" หรือลากคลุมส่วนใดก็ได้ของหน้าเว็บ
★ คำแปลอยู่บนรูปภาพโดยตรง ตรงที่ข้อความต้นฉบับเคยอยู่
★ ชอบแบบรายการมากกว่า? ดูทีละบรรทัดข้างรูปภาพ แล้วคลิกเพื่อคัดลอก
★ แปลได้ 31 ภาษา
★ ฟรีตั้งแต่คลิกแรก: ไม่ต้องใช้คีย์ ไม่ต้องมีบัญชี รูปภาพอยู่ในคอมพิวเตอร์ของคุณ
★ ฉลาดขึ้นด้วย AI ถ้าต้องการ: Gemini, Claude, โมเดลในเครื่อง หรือ API ใดก็ได้ที่เข้ากันได้กับ OpenAI
★ ใช้กับเฟรมวิดีโอ พื้นหลัง และ canvas ได้ด้วย: อะไรก็ได้ที่คุณเห็นบนหน้าเว็บ
★ ฟรีและโอเพนซอร์ส: ไม่มีโฆษณา ไม่มีบัญชี ไม่มีการติดตาม

เริ่มได้สองวิธี
• คลิกขวาที่รูปภาพแล้วเลือก "แปลรูปภาพ"
• หรือกด Alt + Shift + T (⌥ ⇧ T บน Mac) คลิกขวาที่หน้าเว็บแล้วเลือก "แปลพื้นที่…" หรือใช้ปุ่มในป๊อปอัป จากนั้นลากคลุมข้อความที่ต้องการแปล ใช้ได้กับเฟรมวิดีโอ พื้นหลัง และ canvas ด้วย
• กด Esc เพื่อยกเลิก และตั้งปุ่มลัดอื่นได้ในการตั้งค่าปุ่มลัดของ Chrome

บนรูปภาพหรือเป็นรายการ
• บนรูปภาพ (ค่าเริ่มต้น): ลบข้อความต้นฉบับออกจากรูปภาพ แล้ววางคำแปลไว้ที่เดิม ด้วยสี ขนาด ความหนา และการจัดแนวที่วัดจากรูปภาพ ทั้งหมดเกิดขึ้นในคอมพิวเตอร์ของคุณและไม่มีค่าใช้จ่าย
• คำแปลที่ยาวเกินพื้นที่จะแสดงเป็นบับเบิลเล็กๆ ข้างๆ แทน พร้อมเส้นโยงไปยังต้นฉบับ
• รายการ: ข้อความแต่ละส่วนพร้อมคำแปล ในการ์ดข้างรูปภาพ คลิกบรรทัดเพื่อคัดลอก หรือคัดลอกทั้งหมดในครั้งเดียว
• ชื่อ ราคา และข้อความที่เป็นภาษาของคุณอยู่แล้วจะคงไว้ตามเดิม

เลือกตัวแปล
• ด่วน (ค่าเริ่มต้น): ฟรี ไม่ต้องใช้คีย์ อ่านข้อความภาษาเวียดนามและภาษาอังกฤษในคอมพิวเตอร์ของคุณ แล้วให้ Google แปลภาษาแปล เหมาะที่สุดกับข้อความที่ชัดเจน เช่น เมนู โพสต์ และภาพหน้าจอ
• Gemini: คีย์ฟรีจาก Google AI Studio มีขีดจำกัดรายวัน อ่านมีม ลายมือ และฟอนต์ตกแต่งได้ดีกว่ามากในทุกภาษา
• Claude: จ่ายตามการใช้งาน ด้วยคีย์ API ของคุณเอง
• ในเครื่อง: ฟรีและออฟไลน์ ด้วย Ollama หรือ LM Studio และโมเดลที่มองเห็นรูปภาพได้
• อื่นๆ: API ใดก็ได้ที่เข้ากันได้กับ OpenAI เช่น OpenRouter
• แปลเป็น: เวียดนาม เช็ก อังกฤษ สโลวัก เยอรมัน ฝรั่งเศส สเปน อิตาลี โปรตุเกส โปแลนด์ ฮังการี ยูเครน ดัตช์ สวีเดน เดนมาร์ก นอร์เวย์ ฟินแลนด์ กรีก ตุรกี โรมาเนีย โครเอเชีย จีน (ตัวย่อและตัวเต็ม) ญี่ปุ่น เกาหลี ไทย อินโดนีเซีย มาเลย์ ฟิลิปปินส์ ฮินดี อาหรับ

อินเทอร์เฟซ 31 ภาษา
ป๊อปอัปและทุกอย่างที่ Snap Translate แสดงบนหน้าเว็บมีครบทั้ง 31 ภาษาที่แปลได้ รวมถึงภาษาอาหรับ (ขวาไปซ้าย) ใช้ตามเบราว์เซอร์ของคุณ หรือเลือกใน "ภาษาและรูปลักษณ์" รูปลักษณ์แบบมืด สว่าง หรือเหมือนเบราว์เซอร์

ความเป็นส่วนตัว
ไม่มีอะไรออกจากเบราว์เซอร์ของคุณจนกว่าคุณจะขอคำแปล เมื่อใช้ด่วน รูปภาพจะอยู่ในคอมพิวเตอร์ของคุณ และมีเพียงข้อความที่พบในรูปภาพเท่านั้นที่ส่งไปยัง Google แปลภาษา เมื่อใช้ตัวแปล AI จะส่งเฉพาะภาพหน้าจอของพื้นที่ที่คุณเลือกไปยังผู้ให้บริการนั้น พร้อมคีย์ API ของคุณ คีย์จะบันทึกไว้ในอุปกรณ์นี้เท่านั้น ไม่มีการวิเคราะห์ ไม่มีบัญชี ส่วนขยายทำงานเฉพาะในแท็บที่คุณเริ่มแปลเท่านั้น ไม่ทำงานบนทุกเว็บไซต์ หากคุณเขียนถึงฉันผ่าน "ปัญหาหรือไอเดีย?" ข้อความจะส่งถึงฉันทางอีเมล และจะไม่มีอะไรถูกส่งจนกว่าคุณจะกด "ส่ง"

ปัญหาหรือไอเดีย?
คลิก "ปัญหาหรือไอเดีย?" ที่ด้านล่างของป๊อปอัปแล้วเขียนถึงฉัน ฉันอ่านทุกข้อความ
